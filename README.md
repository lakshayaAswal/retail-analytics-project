# 📊 Retail Analytics Dashboard

An end-to-end retail analytics project that transforms retail sales, product, store, and inventory data into actionable business insights using Python, Pandas, Jupyter Notebook, and an interactive HTML dashboard.

## 🚀 Project Overview

This project analyzes retail business performance across sales transactions, product categories, store locations, and inventory levels.

It combines Python-based exploratory data analysis with an interactive dashboard to help understand sales trends, product performance, profitability, and inventory health.

The project covers sales data from January 2021 to October 2025, with an inventory snapshot dated October 31, 2025.

## 🌐 Interactive Dashboard

**Live Dashboard:** [View Retail Analytics Dashboard](https://lakshayaaswal.github.io/retail-analytics-project/Retail%20Analytics%20Dashboard.html)

The dashboard provides an interactive view of retail performance through KPI summaries, charts, business insights, and inventory analysis.

### Dashboard Features

- **Executive Summary:** Overview of important retail performance indicators.
- **Sales Analysis:** Explore sales trends across different years.
- **Category Analysis:** Compare performance across product categories.
- **Product Analysis:** Understand product-level performance.
- **Store Analysis:** Explore retail performance across store locations.
- **Inventory Monitoring:** Review stock levels and replenishment indicators.
- **Business Insights:** Identify trends and potential areas for improvement.
- **Interactive Filters:** Filter dashboard data by year and product category.
- **Responsive Design:** Access the dashboard on desktop and mobile devices.
- **Dark Mode Support:** Dashboard styling adapts to supported system theme preferences.

## 📈 Data Analysis

### 1. Sales Analysis

The sales dataset supports analysis of:

- Sales trends over time.
- Revenue generated by retail transactions.
- Quantity sold.
- Sales performance across different channels.
- Discount patterns.
- Store-level and product-level performance.

### 2. Product Analysis

The product dataset supports analysis of:

- Product categories and subcategories.
- Product pricing and cost.
- Brand-level product information.
- Differences in product performance.

### 3. Store Analysis

The store dataset supports analysis of:

- Sales performance across store locations.
- Geographic distribution of stores.
- Store types, including mall, community, and high-street locations.
- Relationships between stores and sales transactions.

### 4. Inventory Analysis

The inventory dataset supports analysis of:

- Stock available at each store.
- Reorder points and safety stock.
- Inventory replenishment requirements.
- Last restock dates.
- Potential inventory shortages.

### 5. Business Intelligence Dashboard

The interactive HTML dashboard brings important business metrics and visualizations together in one interface.

Users can explore different sales years and product categories, review product and store performance, and examine inventory-related indicators.

## 💻 Getting Started

### Prerequisites

Install Python and the required analysis libraries.

```bash
pip install pandas numpy matplotlib jupyter
```

### Clone the Repository

```bash
git clone https://github.com/lakshayaAswal/retail-analytics-project.git
```

Navigate to the project directory:

```bash
cd retail-analytics-project
```

### Run the Jupyter Notebook

Start Jupyter Notebook:

```bash
jupyter notebook
```

Open `retail.ipynb` and execute the notebook cells.

Make sure the CSV files are available in the same working directory as the notebook.

### Open the Dashboard

Open `Retail Analytics Dashboard.html` in a modern web browser.

The dashboard uses Chart.js, loaded through a CDN, so an internet connection is required for that external library to load.

No separate application server is required to open the static HTML dashboard.
